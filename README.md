# ばんどう農園 Instagram記事メーカー

ばんどう農園のInstagram投稿文を、スマホでも作りやすい小さなWebアプリです。

## できること

- 季節に合わせた投稿文を作れます
- ピーマン、トマト、スイカ、なす、いちご、山菜、ジャムなどを選べます
- 北海道・新ひだか町三石の雰囲気を入れた文章になります
- 文章をコピーしてInstagramに貼り付けられます

## 動かし方

1. このフォルダの `index.html` をダブルクリックします
2. ブラウザでアプリが開きます
3. 季節や投稿したいものを選んで「記事を作る」を押します
4. 文章を確認して「コピー」を押します
5. Instagramに貼り付けて、必要なら一言だけ書き足します

## ファイル

- `index.html`: 画面の中身です
- `style.css`: 見た目を整えるファイルです
- `script.js`: 投稿文を作るための動きです
